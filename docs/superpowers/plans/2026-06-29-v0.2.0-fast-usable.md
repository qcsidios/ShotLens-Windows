# ShotLens Windows v0.2.0-fast Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 用最快速度交付一个能安装、能应用内升级、能截图翻译、能显示和复制结果的 Windows 基础可用版。

**Architecture:** 直接选用已通过 Windows CI 的 PaddleSharp OCR。截图框选使用 Windows 桌面位图快照和轻量选择窗，先保证闭环可用；后续再替换为更严格的 DXGI 多屏选择体验。主窗口保持 WPF，设置、翻译和工作流状态放在 Core，平台能力放在 Platform/App。

**Tech Stack:** .NET 8、WPF、Windows Forms 屏幕快照、PaddleSharp OCR Worker、SiliconFlow OpenAI-compatible Chat Completions、Inno Setup、GitHub Releases 更新。

---
